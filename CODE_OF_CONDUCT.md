# Seyvo Code of Conduct

Anyone may use Seyvo and contribute to its development. Everyone participating in this project's issues, pull requests, discussions and other project spaces must follow this code.

## Expected conduct

- Be respectful and welcoming across backgrounds, identities, abilities and experience levels.
- Discuss ideas and code constructively. Give useful context, accept good-faith feedback and respect maintainers' decisions about project scope.
- Respect privacy. Remove API keys, private transcripts, clipboard contents and personal information from reports, logs and screenshots.
- Credit others' work and respect their licenses.

Harassment, discrimination, threats, sexual harassment, personal attacks, doxxing, spam and repeated disruption are not acceptable. Do not retaliate against someone for reporting a concern.

## Reporting and enforcement

Use GitHub's reporting or blocking controls for abusive content. For project-specific concerns, ask a maintainer for a private reporting channel without posting sensitive details in a public issue. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).

Maintainers may edit or remove content, request corrections, restrict participation temporarily or permanently, or take other proportionate action. They consider context, severity and repeated behavior, and should explain decisions where appropriate without exposing private reports. Anyone affected may request reconsideration with relevant new information. No response-time guarantee is offered.

This code applies in project spaces and when someone represents the project publicly. It governs participation; use and distribution of the software are governed by the [MIT license](LICENSE).
