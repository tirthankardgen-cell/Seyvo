## Section 6 settings audit

General, Dictation, Personalization, Privacy, Appearance, Troubleshooting and About are implemented. Sound cues are original synthesized 150 ms tones played through the Windows mixer, off by default. Preview reports playback failures; an automatic cue failure does not abort a dictation. Coding vocabulary is opt-in, lists every term, merges behind the user's dictionary and never inspects app contents. Bubble size offers compact/standard/large; placement offers top, bottom, near-caret and custom positions. The build identifier is compiled from Git and marks modified checkouts.

Near-caret placement is experimental and uses the activation-time caret with a bottom fallback. Custom placement persists horizontal/vertical percentages and keeps the bubble inside the current work area. Preview shows placement without opening a microphone.

Explicit deviations: native Windows title controls are used instead of custom titlebar buttons. Plain CSS and React state replace optional styling/state libraries. A minimal C# sidecar replaces the suggested Rust module. npm with a committed lockfile replaces pnpm. Hold-to-talk, snippets, ARM64 and automatic update channels are optional features not shipped. These deviations are visible in support documentation rather than exposed as inert controls.

## Milestone and delivery gates

- M0: foundation/build/IPC/security scaffolding implemented and checked.
- M1: real provider/recorder/native vertical slice implemented and observed using generated speech and short human English/Hindi/Hinglish samples. Required language checks passed; remaining target and Windows interruption acceptance is listed separately.
- M2: native safety, recovery, lifecycle, tray/startup and monitor logic implemented; remaining physical Windows cases are recorded above.
- M3: required settings gaps found in the audit are implemented, with lifecycle/layout/persistence regressions covered. Physical accessibility acceptance remains open.
- M4: source, installer, licensing/privacy/security/architecture/support documentation, supply-chain reports, checksums and GitHub prereleases delivered. Stable commercial release still requires the acceptance gates and owner-controlled signing/brand/provider decisions in `commercial-readiness.md`.

Installed 0.1.7 has passed the specified human English/Hindi/Hinglish checks, matching prompted sentences and native targets with clipboard preservation and microphone stop. This fulfills the spoken-language gate without claiming universal recognition accuracy. Physical Windows, shutdown stability and owner-controlled commercial launch gates remain open.

Version 0.1.7 adds exact native screenshot and Chromium text/HTML clipboard restoration checks, two installed live-Google clipboard-paste cycles, transparent overlay alpha checks and terminal dismissal. Both startup values survived installed restart; --startup stayed in the tray and a second launch reused the instance.
