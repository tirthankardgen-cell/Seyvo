# Working brand and commercial launch

Seyvo is a working name, not a cleared trademark. The supplied brief flags the phonetically similar voice product Sayvo (`sayvo.online`). No formal trademark search or legal clearance has been completed by this implementation.

Before marketing a production release, the owner should search India Classes 9 and 42 and each intended launch jurisdiction, including phonetic variants, unregistered/common-law products, company registries, domains, app stores and package/repository names. Record search date, databases, results and qualified review. Confirm rights to the product name, publisher identity and support contact. Do not imply that the existing GitHub repository establishes trademark rights.

Original generated icon/wordmark artwork is included; it contains no competitor assets. System Segoe UI is referenced, not redistributed. Source license is MIT as directed by the brief, allowing commercial use with copyright/license notice preservation. Google API use remains governed by Google; the app does not sell API access or promise free service.

For a rebrand, update `src/shared/brand.ts`, Electron builder metadata/appId, package metadata, installer startup cleanup name, icon resources and documents together. Changing appId/profile paths requires an explicit data/startup migration plan. Do not silently strand stored keys or histories.
